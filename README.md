# Responsive Image Gallery

A complete, polished, and fully responsive Image Gallery web project built using purely **HTML, CSS, and Vanilla JavaScript**.

## Features

- **Responsive Grid Layout:** Adapts flawlessly to desktop, tablet, and mobile screens.
- **Dynamic Category Filtering:** Filter images smoothly by categories such as Nature, Architecture, Animals, and Art.
- **Interactive Lightbox:** Click on any image to open it in a full-screen, high-resolution modal.
- **Keyboard Navigation:** Navigate through the lightbox images using the `Left Arrow` and `Right Arrow` keys, and close it with the `Escape` key.
- **Modern Aesthetic:** Features a sleek, Monochromatic Slate dark-mode design with striking cyan accents, smooth transitions, and premium hover effects.

## Technologies Used

- **HTML5:** Semantic structure and accessibility considerations.
- **CSS3:** Flexbox & Grid layouts, CSS Variables for theming, smooth keyframe animations, and hover transitions.
- **Vanilla JavaScript:** DOM manipulation, array filtering, and event handling without the need for external libraries or frameworks.

## Setup and Usage

To run this project locally, simply clone the repository or download the files and open the `index.html` file in your preferred web browser. No local server or build tools are required!

```bash
# Example
open index.html
```
